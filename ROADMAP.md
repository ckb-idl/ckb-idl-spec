# IDL Roadmap

This document is non-normative. It lists work intentionally deferred beyond
IDL 0.1.0.

- Script argument interfaces.
- `WitnessArgs.input_type` and `WitnessArgs.output_type` interfaces.
- Type Script and cell-data interfaces.
- Code-cell identity verification and version-aware caching for scripts referenced
  with `hash_type = type`.
- Molecule encoding profile and `.mol`-to-IDL generation.
- Optional extension namespaces and wallet-specific UI hints.
- Signing and partial-signing metadata.
- Optional discovery URI fields in a future binding-trailer version.
- Manual-IDL authoring and attestation tooling for legacy scripts.
- Additional encoding profiles and generated language bindings.
